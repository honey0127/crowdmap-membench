## 1. 연구 질문
같은 메모리 유지 비용과 재확보 비용 조건에서, 상태 기반 학습 예측은 고정 타임아웃과 단순 규칙보다 메모리 낭비를 얼마나 줄이는가? 그 이득은 실제 할당기와 메모리 제한 환경에서도 유지되는가?

## 2. 문제 정식화
- 요청 본문 버퍼의 사용량 D(t)를 높이 조각으로 나눈다. 높이 y의 조각은 D가 y 아래로 내려간 때부터 다시 y에 닿을 때까지 논다(놀이 시간 g).
- 조각을 쥐고 있으면 낭비 비용이 들고, 반납했다가 다시 쓰이면 재확보 비용(페이지 폴트·반납 CPU)이 든다. 미리 잡아 두기는 재확보 횟수를 줄이지 못하므로 결정 변수는 반납 시점뿐이다.
- 손익분기 시간 T* = C_reacquire / C_retain(초당). 비용 = 재확보 횟수(바이트) + 낭비(바이트·초)/T*.
- 스키 대여 대응: 쥐기 = 빌리기(초당 1/T*), 반납 후 재확보 = 사기(비용 1), b = T*. 다시 쓰이지 않는 조각은 반납 비용이 0이라 원 문제보다 유리하다.
- T*는 비용 모델의 매개변수다. T*가 작다는 것만으로 실제 메모리 부족을 입증하지 않는다(3.2절에서 따로 검증한다).
- T*의 현실 범위(계산): 재확보 비용을 재확보 CPU 시간으로, 단가를 공용 클라우드 값으로 두면 T* = (1 MiB 재확보 시간) × 1,024 × (vCPU 초 단가 / GB 초 단가)다. AWS Fargate 단가 비 9.10과 WSL 실측 0.17–0.27 ms/MiB(THP 기본)로 1.6–2.5초, THP on(0.037–0.10 ms/MiB)으로 0.34–0.97초다. 반납 CPU와 지연을 뺐으므로 낮게 잡은 값이다. 고정 RAM 장치에서는 예산에 닿기 전까지 유휴 메모리의 한계 비용이 0에 가까우므로 실효 T*는 3.2절에서 정한다.

## 3. 실험 구성
### 3.1 비용 모델 실험 (시뮬레이션, T* 민감도)
- T* ∈ {0.3, 1, 3, 10}초에서 정책별 비용·낭비·재확보량을 잰다. 목적: 어떤 비용 조건에서 AI가 유리한지 설명한다.

### 3.2 메모리 압박 실험 (C++ 실측)
- 컨테이너(cgroup) 메모리 상한을 바꿔 가며 같은 일정을 재생한다.
- 지표: 실제 점유량·최대 RSS, 페이지 회수(pgscan·pgsteal), major/minor 폴트, 재확보 지연 p50·p99, 할당 실패·OOM.
- 목적: 메모리가 제한된 환경에서 유용하다는 주장을 뒷받침하고 실효 T*를 정한다.

### 3.3 비교군
| 비교군 | 검증하려는 것 | 실행 위치 |
|---|---|---|
| 고정 타임아웃(검증 데이터로 조정) | AI 없이 타임아웃만 조정했을 때 | 시뮬 + 청크 풀 |
| 2특징 규칙(검증 데이터로 선택) + 대체 | 단순한 데이터 기반 정책으로 충분한지 | 시뮬 + 청크 풀 |
| 그래디언트 부스팅 + 점수 구간별 반납 시점 | 복잡한 예측 모델의 추가 이득 | 시뮬 + 청크 풀 |
| 위 + 대체 장치 | 예측 실패 대응 | 시뮬 + 청크 풀 |
| 생존 모델(매듭별 분류기 → 생존 곡선 → 조각별 기대 비용 최소 반납 시점) + 대체 | T*마다 다시 학습하지 않는 단일 모델의 이득. 2026-10-24 기준 탐색적, 봉인 시험으로 확정 | 시뮬 + 청크 풀 |
| PSK 결정적·무작위(Purohit·Svitkina·Kumar, NeurIPS 2018) | 기존 학습 보강 온라인 알고리즘 대비 | 시뮬 + 청크 풀 |
| jemalloc 기본(dirty_decay_ms 10,000) | 실제 할당기 기본 동작 대비 | 실측만 |
| glibc 기본(trim_threshold·top_pad·mmap_threshold 기본) | 다른 범용 할당기 기본 동작 대비 | 실측만 |
| 즉시 반납·반납 안 함 | 양 끝 참고값 | 시뮬 + 청크 풀 |
| 오라클(g를 앎) | 유체 모델 안의 비용 하한(구현 불가) | 시뮬만 |

- jemalloc 감쇠는 고정 타임아웃이 아니다. 안 쓰는 dirty 페이지를 시그모이드 감쇠 곡선에 따라 점진적으로 정리한다(jemalloc 문서). glibc는 힙 꼭대기 trim과 mmap 문턱으로 반환한다. 둘 다 실측 기준선으로만 쓰고 타임아웃과 동일시하지 않는다.
- PSK 대응: 결정적 알고리즘은 예측이 y ≥ b이면 λb에, 아니면 b/λ에 산다(일관성 1+λ, 강건성 1+1/λ). 이 연구에서는 분류 확률 ≥ 0.5를 'y ≥ b'로 쓴다. 무작위 알고리즘은 연속 시간 판(반납 시각 밀도 e^{τ/b}/(b(e^{K/b}−1)), K = λb 또는 b/λ)으로 비교한다.

### 3.4 데이터 분리와 일반화
- 트레이스마다 시간 순으로 학습 50% / 검증 25% / 시험 25%로 나눈다. 구간 끝 300초(엠바고) 안에 놀기 시작한 조각은 그 구간에서 빼고, 학습·검증의 g는 구간 끝까지 관찰한 값만 쓴다.
  - 학습: 분류기를 학습한다.
  - 검증: 점수 구간별 반납 시점, 2특징 규칙의 특징 조합, 생존 모델의 배율 κ, PSK의 λ, 대체 장치의 창·여유·최소 유지 시간. 선택은 검증 두 쪽 교차 적합으로 평가한다.
  - 시험: 모든 선택을 확정한 뒤 한 번만 평가한다.
- 트레이스 단위 일반화: 한 트레이스를 통째로 빼고 나머지로 학습·검증한 뒤 뺀 트레이스에서 시험한다(무보정). 뺀 트레이스의 검증 구간으로 반납 시점만 다시 맞춘 경우(국소 보정)도 잰다.
- BurstGPT: 최다 1시간 하나만 쓰지 않는다. BurstGPT_1.csv의 시간당 요청 수 50·75·90·99·100번째 백분위 1시간 창을 뽑아 결과를 분포로 보고한다. 최신 arXiv판 기준 데이터셋은 213일·1,031만 건이고, 지금까지 쓴 BurstGPT_1.csv는 그중 약 61일·143만 건이다.
- 봉인 시험: 방법을 고정한 뒤 쓰지 않은 데이터(Azure LLM 추론 2024 1주, BurstGPT의 다른 날·시간대)에서 한 번만 잰다. 탐색적 변형의 우열은 이 결과로만 주장한다.
- 분류기 시드를 3개 이상 돌려 변동을 보고한다.

### 3.5 대체 장치
- 그림자 장부: 사용량 D(t)는 반납 정책과 무관하게 서버가 관찰한다. 그래서 조각마다 놀기 시작한 시각·가상 반납 시각·재사용 시각을 기록해 AI와 고정 정책의 비용을 같은 장부로 계산한다. 이 값은 실제 관찰 비용이 아니라 같은 입력에 대한 반사실적 추정치임을 명시한다.
- 공정성: AI 쪽도 실측 비용이 아니라 같은 장부로 계산해 비교한다(실측과 추정을 섞으면 단편화 차이가 편향을 만든다).
- 전환 규칙: 최근 W초 동안 AI 장부 비용이 고정 정책보다 (1+ε)배 넘게 크면 고정 정책으로 바꾸고, 바꾼 뒤 최소 H초 유지한다.
- 민감도: W ∈ {60, 300, 900}초, ε ∈ {0, 0.05}, H ∈ {0, 60}초를 모두 잰다.
- 평가: 평균 비용, 워크로드별 최악 비용 증가, 전환 횟수, 전환 지연(분포 변화 시작부터 전환까지).
- 장부는 모든 조각의 실제 g를 관찰하므로, 점수 구간별 반납 시점을 최근 창으로 계속 다시 맞추는 온라인 보정에도 쓸 수 있다(§8, 미구현).

## 4. C++ 실측 설계
- 청크 버퍼 풀: 본문을 고정 크기 청크(256KiB 또는 2MiB)로 담고, 빈 청크는 LIFO로 재사용한다(유체 모델의 높이 조각 구조와 대응).
- 반납 방식(변수): MADV_DONTNEED(즉시 반환·RSS 감소, 다음 접근 시 0으로 채운 새 페이지) / MADV_FREE(메모리 압박 때만 커널이 회수, 그전까지 RSS 유지) / munmap. 풀에 되돌리는 것과 운영체제에 반환하는 것을 구분해 기록한다.
- 지표
| 지표 | 목적 |
|---|---|
| 누적 미사용 메모리 바이트·시간 | 메모리 낭비 |
| 재확보 지연 p50·p99 | 반납의 대가 |
| 실제 점유량·최대 RSS | 반환 효과 |
| minor/major 페이지 폴트 | 운영체제 페이지 처리 |
| 할당·반납 횟수, 정책·예측 CPU | AI 정책 실행 비용 |
| 버퍼 확보 실패율(애플리케이션)과 OOM | 안정성 |

- 애플리케이션의 버퍼 재확보 실패와 운영체제 페이지 폴트는 따로 센다.

## 5. 기여(안, 2026-10-24 시뮬 근거 반영)
1. 상태 기반 반납 예측: 그래디언트 부스팅 모델이 유휴 조각의 상태(사용량, 높이, 최근 유입, 같은 높이의 직전 놀이 시간 등)로 T*보다 오래 쓰이지 않을 확률(또는 생존 곡선)을 예측한다. 순열 중요도 1위는 모든 경우 조각 위치('수준'·'높이')였고, 시간 패턴 특징이 크게 기여한 것은 합성 주기 트레이스뿐이었다. 모델이 배운 것은 시계열 패턴보다 현재 상태이며 이를 그대로 기여로 쓴다.
2. 예측을 반납 결정으로 연결: 점수 구간별 반납 시점(검증으로 보정) 또는 생존 곡선의 기대 비용 최소화로 버퍼 풀의 반납 시점을 정한다. 시뮬에서 T* = 0.3–1초의 고정 타임아웃 대비 비용을 중앙값 7.5–13.1% 줄였고, T* = 1초의 이득은 주로 유휴 메모리 감소(중앙값 −28.5%)였다.
3. 예측 실패에 대한 강건성: 그림자 장부 비교로 안전한 기준 정책에 전환한다. 시뮬에서 T* ≤ 3초의 최악 비용 증가를 +42.4%(AI)·+47.5%(규칙)에서 +2.1% 이하로 줄였다. 평균뿐 아니라 최악 비용 증가와 전환 지연으로 평가한다.
4. 트레이스 사이 이전: 다른 워크로드로 학습한 분류기는 반납 시점만 현장에서 다시 맞추면 쓸 수 있었다(T* = 1초 중앙값 −9.3%, 8승 2무 0패). 고정 타임아웃은 옮기면 나빠졌다(+6.6–+13.4%).
- 주장하지 않는 것: 미리 정한 AI가 잘 맞춘 2특징 규칙보다 항상 낫다는 주장은 하지 않는다(T* = 1초 3승 4무 3패, T* = 3초 1승 1무 8패). 단순 규칙 대비 우위는 봉인 시험으로 확인한 범위에서만 쓴다.

## 6. 예비 결과 (유체 모델 시뮬, 학습 50 / 검증 25 / 시험 25, 트레이스 10개, 시드 0)
고정 타임아웃(검증으로 조정) 대비 시험 구간 비용 변화. 값은 트레이스 간 중앙값 / 최악(%), 괄호는 고정 대비 승/무/패(±0.5%p 안은 무)다.

| 정책 | T* = 0.3초 (n = 9) | T* = 1초 | T* = 3초 | T* = 10초 |
|---|---|---|---|---|
| 2특징 규칙 + 대체 | −5.3 / +0.1 (6/3/0) | −1.9 / +0.0 (5/5/0) | −11.6 / +0.0 (7/3/0) | +1.8 / +9.0 (2/2/6) |
| AI(점수 10칸) + 대체 | −7.5 / +0.0 (6/3/0) | −13.1 / +0.1 (7/3/0) | −5.2 / +2.1 (6/2/2) | +0.0 / +3.7 (4/3/3) |
| (탐색) AI 생존 + 대체 | −6.5 / +0.0 (6/3/0) | −13.9 / +0.2 (7/3/0) | −10.4 / +1.5 (6/3/1) | −1.0 / +6.7 (5/0/5) |
| AI 단독(대체 없음) | −7.5 / +0.4 | −13.3 / +0.2 | −5.6 / +42.4 | +1.7 / +17.6 |
| PSK 결정적 | +8.9 / +42.8 | +0.6 / +15.5 | +4.9 / +51.9 | +7.2 / +35.3 |
| PSK 무작위 | +1.5 / +39.2 | −3.1 / +9.8 | +1.8 / +57.6 | +7.7 / +23.5 |
| 오라클(하한) | −32.7 | −31.6 | −25.9 | −21.3 |

- AI+대체 vs 2특징+대체: T* = 0.3·1·3·10초에서 2/5/2, 3/4/3, 1/1/8, 5/0/5다. T* = 1초에서 AI는 실제 트레이스 3개(az_conv, bg_q99, bg_q100)에서, 규칙은 합성 트레이스 3개에서 이겼다.
- 트레이스 단위 일반화(뺀 트레이스, 국소 보정 + 대체): 중앙값 −2.7 / −9.3 / −6.7 / −0.4%, 최악 +0.0 / +0.1 / +4.4 / +2.3%다. 무보정 고정 타임아웃은 중앙값 +6.6 / +9.9 / +13.4 / +8.1%였다.
- 시드 0·1·2에서 AI+대체 중앙값은 T* ≤ 3초에서 1%p 안에서 움직였다.
- 절대량: T* = 1초에서 AI+대체가 줄인 평균 유휴 보유는 트레이스당 0.4–3.2 MiB였다(살아 있는 본문 평균 0.0–17.6 MiB의 부하).
- 실패 사례: bg_q90(T* = 3초)에서 검증과 시험 사이 부하가 바뀌어 점수 구간별 반납 시점이 어긋났다(AI 단독 +42.4%, AUC 0.81). 분류 순위보다 반납 시점 보정이 약한 고리였다.

## 7. 타당성 위협
- 유체 모델은 단편화가 없다. 같은 빈 메모리에서 기존 할당기(jemalloc·glibc)는 이상적 타임아웃 모델보다 폴트가 1.9–2.3배였다(실측-VM). 이는 AI 정책을 실제 할당기로 옮긴 결과가 아니라 기존 할당기와 이상 모델의 차이다. 청크 풀 실측으로 재현 여부를 확인한다.
- 처리시간은 임시 모델(10ms + 20ms/MB)이고 데이터는 LLM 트레이스다. CrowdMap 워크로드가 아니다.
- 절대 CPU 이득은 작다(즉시 반납도 1코어의 0.4–2.5%). 절대 메모리 이득도 이 부하에서는 MiB 단위다. 상대·절대 수치를 함께 보고한다.
- 생존 모델은 시험 결과를 본 뒤 추가했다(갈림길 선택 편향). 봉인 시험 전에는 우열 근거로 쓰지 않는다.
- 트레이스 10개, 시험 구간 약 15분이다. 부하가 낮은 BurstGPT 창은 시험 조각이 55–119개다. 부호 검정은 서술용이고 다중 비교를 보정하지 않았다.
- BurstGPT 1시간 창은 시간 안에서 부하가 크게 변한다(bg_q99 도착 수 학습 9,024 / 검증 962 / 시험 1,264건).

## 8. 다음 단계
