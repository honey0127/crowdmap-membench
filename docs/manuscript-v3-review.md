## 2. 논리적 모순 검사

### 2.2 ΔR 부호와 의미

**판정**: §7.2에서 "The sign of ΔR = -906.0 MiB requires careful interpretation"으로 시작하여, 음수 ΔR이 정책 결함이 아님을 명확히 설명함. 음수 ΔR에도 불구하고 G1_SMODEL_C가 양수인 이유(ΔH 항의 7:1 비율 상쇄)를 수치로 보여줌. ✓

**판정**: 두 측정이 서로 다른 구현을 대상으로 한다는 점이 §6.5 "Scope note"에 이미 명시됨. §7.3에서 개별 함수 기여도를 추측하지 않음. §8 L10에서 G2가 P1b-based C3에 한정됨을 재확인. ✓

**판정**: §7.5 마지막 단락, §9.5 첫 단락, §9.6에서 "P1b-based C3 policy, BurstGPT trace-driven chunk pool simulation, T* = 2.6 s, specified hardware"로 범위를 명시적으로 제한. "not support the conclusion that ML-based memory reclamation is generally unviable" 문장 포함. ✓

## 4. 남은 수정 사항

### 4.1 경미한 사항

1. **§6.7 G1 분해식**: `c(ΔR + ΔH/T*) = 281.8 × (-906.0 + 6,444.9) = 281.8 × 5,538.9 ≈ 1,560.860 ms`에서 중간값 5,538.9 MiB에 단위(MiB)를 명시하지 않음. 현재 §6과 동일한 표기이므로 manuscript-v3.md §1–§6 범위는 수정 없이 유지함. 추후 개정 시 단위 명시 가능.

2. **§7.4 표 형식**: 내용은 §6.9 Table 12와 동일하지만 Discussion 맥락에서 반복 제시함. 독자가 §7.4를 별도로 참고하지 않아도 §6.9 참조로 충분할 수 있음. 단, 현재 형태도 허용 가능.

3. **§8 L6 "single hardware platform"**: 항목 제목이 다른 항목과 형식이 다름 (다른 항목은 더 긴 설명 포함). 소제목 형식은 일관됨 — 수정 불요.

### 4.2 범위 밖의 미수행 사항

다음 항목은 본 작업 범위 밖으로, manuscript-v3.md에 포함하지 않은 사항이다.

- **독립 Copilot 확증**: final-report-draft.md §10.6에 따르면 G2 PASS 시 진행 예정이었으나 G2 FAIL로 미실행. §9.7에 "독립 확증을 계획했으나 G2 FAIL로 실행하지 않았다"를 명시하는 것이 가능하나, 현재 §9.7은 미래 방향에 집중하여 이 사항을 생략함. 필요 시 §8에 추가 한계로 기재 가능.

- **H* (사전 학습비 회수 기간)**: G_op ≤ 0이므로 유한한 H*가 없음. 이미 Task A 결과(§6.5)에서 간접적으로 처리됨.
