## 3. 논리적 불일치 목록

### 3.1 [치명] §8.1 ΔR 해석 오류 — 첫 번째 문장

**위치**: §8.1, 표 아래 주의 단락, 첫 번째 문장.

> (보고서) "현재 ΔR = −906 MiB는 **C3가 규칙보다 메모리를 덜 반환한다**는 뜻이다."

**오류**: ΔR = R_rule − R_C3 = −906 → R_C3 > R_rule → C3의 재확보량이 규칙보다 많다. 재확보량이 많다는 것은 C3가 메모리를 더 적극적으로 반환했음을 뜻한다(반환 → 나중에 필요해 재확보). "덜 반환한다"는 방향이 반대다.

**올바른 해석**: "현재 ΔR = −906 MiB는 C3의 재확보량이 규칙보다 많다는 뜻이다 (C3가 메모리를 더 적극적으로 반환한다). c×ΔR = −255.3 ms는 G_model을 낮추는 방향이다."

---

### 3.2 [치명] §8.1 ΔR 해석 오류 — 두 번째 문장

**위치**: §8.1, 표 아래 주의 단락, 두 번째 문장.

> (보고서) "이는 **C3가 규칙보다 메모리를 더 많이 반환하는 방향**이며, 현재 정책 설계와는 반대 방향이다."

**오류**: 손익분기 조건 ΔR ≥ +2,092.837 MiB는 R_rule − R_C3 ≥ +2,092.837 → R_rule >> R_C3 → 규칙의 재확보량이 더 많다 → C3가 메모리를 덜 반환하는(더 보수적으로 보유하는) 방향이다. "C3가 더 많이 반환"은 반대다.

**올바른 해석**: "이는 C3가 규칙보다 재확보량을 대폭 줄이는 방향이다 (C3가 메모리를 덜 반환하고 더 보수적으로 보유). 현재 C3는 규칙보다 더 적극적으로 반환하므로 (ΔR < 0), 손익분기 방향은 현재와 반대다."

**파급 주의**: 두 문장의 오류가 서로 다른 방향이지만 "현재 정책 설계와는 반대 방향"이라는 결론은 우연히 맞다. 단, 그 경로(이유)가 틀렸으므로 양쪽을 모두 수정해야 한다.

---

### 3.3 [치명] 부록 B 용어 — ΔR 정의 오류

**위치**: 부록 B 용어 정리표, ΔR 항목.

> (보고서) "ΔR | R_rule − R_C3 (규칙 대비 C3의 재확보량 감소분, **음수면 C3가 더 적게 반환**)"

**오류**: ΔR < 0이면 R_C3 > R_rule → C3의 재확보량이 더 많다 → C3가 더 많이 반환한다. "더 적게 반환"은 방향이 반대다.

**올바른 정의**: "ΔR | R_rule − R_C3 (규칙 대비 C3의 재확보량 차이; 음수면 C3의 재확보량이 더 많다, 즉 C3가 더 적극적으로 메모리를 반환한다)"

---

### 3.4 [경미] §8.1 손익분기표 — 부등호 방향

**위치**: §8.1 표, '손익분기 경계' 열.

| 변수 | 표의 경계 | 올바른 경계 |
|------|----------|------------|
| ΔI | ≤ 1,560.860 ms | **< 1,560.860 ms** |
| T* | ≤ 1.774 s | **< 1.774 s** |
| c | ≥ 434.37 µs/MiB | **> 434.37 µs/MiB** |
| ΔH | ≥ 24,553.70 MiB·s | **> 24,553.70 MiB·s** |
| ΔR | ≥ +2,092.837 MiB | **> +2,092.837 MiB** |

**이유**: 판정 기준이 G_model **> 0** (엄격 부등호)이므로, 경계값에서 G_model = 0 (미통과). 경계 자체는 통과 조건이 아니므로 ≤/≥가 아니라 </> 표기가 정확하다. 경계값 자체(1,560.860 ms 등)는 맞다.

---

### 3.5 [명확성] §4→§7 평가 차원 연결 부재

**위치**: §4 마지막 단락과 §7 사이.

**문제**: v2 봉인 판정(H1v2/H2v2/H3v2 충족)이 시뮬레이션 비용 모델 기반이고, G2 판정이 실제 CPU 오버헤드 기반임을 명시하는 연결 문장이 없다. 두 판정이 서로 다른 가설을 검정하므로, v2 PASS와 G2 FAIL이 모순처럼 보일 수 있다.

**권장**: §7.1 또는 §7.6 도입부에 한 문장 추가. 예: "v2 봉인 판정은 시뮬레이션 비용 모델(c×(ΔR+ΔH/T*))이 C3의 메모리 절감 가치를 측정했다. G2 판정은 그 절감 가치에서 C3 경로의 실제 추가 CPU 비용을 뺐을 때 순이득이 있는지를 검정한다. 두 판정은 서로 다른 가설을 측정하므로 결과가 다를 수 있다."

이는 기술 오류가 아니라 명확성 문제다. 논문 작성 시 반드시 설명이 필요한 부분이다.
