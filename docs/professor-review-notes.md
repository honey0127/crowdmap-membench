## 연구 질문

LLM 추론 서버의 청크 풀(chunk pool) 반환 정책으로서 AI 기반 경로(P1b 65³ 룩업 테이블)가 고정 규칙 경로 대비 경제적으로 유리한가? 구체적으로, C3 정책이 300초 창(window) 단위에서 반환량 증분(ΔR)과 보유 시간 비용 감소(ΔH/T*)에서 얻는 경제적 이득이 C++ 구현 기준 측정된 AI 경로의 추가 CPU 비용(ΔI)을 초과하는가를 사전 등록된 비용 모델 G\_model = c·(ΔR + ΔH/T\*) − ΔI > 0으로 검증한다. 단일 변수 손익분기 분석에서 현재 ΔI를 35.1%, T\*를 31.8%, c를 54.1% 각각 개선하거나 ΔH를 46.5% 증가시키면 단독으로 손익분기를 넘을 수 있으나, 복합 조정(ΔI 20%+T\* 17% 동시 감소) 시에도 G\_model ≈ +8 ms로 σ=75.831 ms 이내에 머물러 아직 안정적인 경제적 타당성이 성립하지 않음을 보인다.

---

## 핵심 발견

- **G2 FAIL — AI 경로 CPU 비용이 경제적 이득을 초과**: C++ 하네스(G2W3) 420창 × 3회 공식 측정 결과 평균 ΔI = 2,405.932 ms, 평균 G\_model = −845.072 ms (σ=75.831 ms). 세 번의 독립 반복 모두 G\_model > 0 기준 미달. G1 단계 유체 모델 추정치(+1,560.860 ms)와의 괴리가 성립 거부의 직접 원인.

- **G1→G2 괴리의 구조적 원인**: G1은 AI 경로의 CPU 비용(ΔI)을 측정하지 않고 경제적 이득(c·(ΔR + ΔH/T\*))만 추정한다. G2에서 비로소 측정된 ΔI = 2,405.932 ms가 G1 추정 이득 1,560.860 ms를 845 ms 초과하여 경제적 타당성이 성립하지 않는다. 이는 G1을 통과했음에도 G2에서 실패할 수 있음을 명확히 보여 주는 사례다.

- **Task A: Python 구현으로는 예산 초과가 불가피**: Python AI 파이프라인의 CPU 비용은 창당 허용 예산(0.1 ms/창 × 300 s / 1000 = 측정 기준)의 8–127배. C++ 재구현의 필요성을 선험적으로 증명하였으며, 이것이 C++ G2 측정의 근거.

- **Task B: 정보는 충분하나 비용이 문제**: Placebo 실험에서 창당 대응(per-chunk correspondence)이 C3 모의 이득의 99.4–99.8%를 설명함. AI 경로가 올바른 정보를 사용하고 있으나 그 연산 비용(ΔI)이 현 단계에서 이득을 상쇄.

- **v1 → C3 → v2 개선 경로 성립**: v1 H2 실패(AI < rule+fallback, 고정 T\*=1s)가 C3 설계(AI/rule 경로 전환, 적응형 T\*=2.6s)를 동기화했으며, v2에서 H1v2(−2.34%p), H2v2(−9.02%p), H3v2(p=3.4×10⁻⁵) 세 가설 모두 통과. G2 FAIL은 v2 가설 거부가 아니라 AI 경로의 연산 비용 문제.
