# 현행 연구 지침 (2026-10-31)

> 이 문서는 지금 연구의 질문, 결과의 보고 순서, 쓰는 표현과 쓰지 않는 표현을 정한다.
> 논문을 쓰거나 AI 코딩 도구로 작업할 때는 이 문서를 먼저 따른다. 다른 문서와 다르면 이 문서를 따르고, 다른 점을 알린다.
> 사전 등록 문서와 과거 결과 문서는 고치지 않고 당시 기록으로 보존한다(§6).

## 1. 연구 질문과 대상

- **핵심 질문**: 예측 기반 메모리 반납 정책이 자신의 학습·추론 CPU 비용까지 회수할 수 있는가?
- **대상**
  - 요청 본문을 담는 1 MiB 청크 풀에서, 놀고 있는 청크를 언제 운영체제에 돌려줄지 정한다.
  - 결정 변수는 반납 시점 하나다. 미리 확보해 두는 것은 재확보 횟수를 줄이지 못하므로 다루지 않는다.
- **비용 모델**
  - 비용 = 재확보 MiB + 낭비 MiB·초 ÷ T*다.
  - 판정 T* = 2.6초다. 연구자 WSL에서 잰 재확보 비용(1 MiB 청크, 4 KiB 페이지)에 AWS Fargate 가격 비율을 곱해 정했다. 가격 비율은 모델링 가정이다.
  - 비용 단위 1은 CPU 281.8 µs(c)에 해당한다.
- **정책**(정의는 `docs/prereg-v2.md` §3)
  - 고정-온라인: 반납 시점 하나를 그림자 장부로 온라인 보정한다.
  - 2특징 규칙: 특징 2개로 나눈 칸마다 반납 시점을 온라인 보정하고, 대체 장치를 붙였다(규칙-온라인+대체).
  - v1 주 AI: 생존 모델(HistGradientBoosting, 매듭 10개)이 조각별 반납 시점을 내고 κ를 온라인 보정하며, 대체 장치를 붙였다(AI생존κ-온라인+대체).
  - C3: 최근 300초 그림자 장부 비용이 낮은 쪽으로 v1 주 AI와 2특징 규칙 사이를 전환한다(AI→규칙대체).
  - 오라클: 조각의 놀이 시간을 아는 비용 하한이다. 구현할 수 없다.
- **평가 모델**: 청크 풀 유체 모델 시뮬레이션이다. 3단계 재생에서 재확보량은 실제 청크 풀과 같았다. 단편화, 백그라운드 회수, 메모리 제한은 모델에 없다.

## 3. 보고 규칙

1. v1의 H2 미충족을 먼저 보고하고, C3로 바꾼 이유와 과정을 쓴 뒤 v2·A·B를 시간순으로 공개한다. v2만 골라 논문을 구성하지 않는다.
2. 사전 등록 판정은 당시의 판정 출력 그대로 인용한다. 사후 재계산은 '사후'로 표시하고 판정을 대신하지 않는다.
3. v2의 −2.34%p와 −9.02%p는 청크 풀 유체 모델 시뮬레이션 결과다. 실제 운영 비용, 클라우드 요금, RSS가 줄었다고 쓰지 않는다.
4. T* = 2.6초는 WSL 실측과 Fargate 가격 비율로 정한 평가 기준이다. 모든 운영 환경의 손익분기 시간으로 쓰지 않는다.
5. A의 CPU는 Python 3.12·scikit-learn 1.9 단일 스레드 구현에서 잰 값이다. 최적화한 C++ 구현으로 일반화하지 않는다. 반대로 "C++이면 순이득이 생긴다"고도 쓰지 않는다.
6. B는 개발 데이터의 사후 분석이다.
   - 쓰는 표현: "같은 30초 구간 안에서 예측값과 조각의 대응을 무작위로 끊으면 C3의 시뮬레이션 이득이 거의 사라졌다."
   - 쓰지 않는 표현: "AI 정보가 (순)비용을 줄였다", "조각별 정보의 인과 기여도가 2.49%p다".
   - 위약 실행은 클라우드 컨테이너에서 한 번 했다. 연구자 PC에서는 요약만 다시 계산했다. 둘을 묶어 '재현했다'고 쓰지 않는다.
7. 7번 계산(봉인 데이터의 예측 비용 추정, T* 민감도)은 사후 계산이다. 가정(결정당 예측 비용 동일, 메모리 단가 고정, 학습비 제외)과 범위(T* 0.3~10초)를 함께 쓴다. 봉인 자료에서 순비용 탈락을 직접 확증했다고 쓰지 않는다. T* 10초 밖으로 넓혀 말하지 않는다.
8. 모든 수치에 (시뮬)(실측)(계산)(추정)을 붙이고, 데이터를 [봉인 v1]·[봉인 v2]·[개발]로 구분한다.
9. 아래는 현재 기여로 쓰지 않는다. 초기 계획이고 실제 구현과 다르다.
   - 버퍼 선확보
   - 낭비–지연(W–A) 파레토 곡선
   - LSTM·1D-CNN 예측기
   - 확보 지연 L
   - CrowdMap v5 큐·스레드 풀 실험대
10. jemalloc 감쇠를 고정 타임아웃과 같다고 쓰지 않는다. 직접 비교하지 않았다. 고정-온라인은 별도의 고정 타임아웃 기준선이다.
11. 문서 문장은 "~했다/~한다"로 끝낸다. 결과 절에는 관측만 쓰고, 해석은 논의 절에 쓴다.
